## 5. Setup Progress Checklist

### Phase 1: Shopify Dev Dashboard App
- [ ] Logged into Shopify Partners account
- [ ] Created new app (manually)
- [ ] Noted API key (Client ID)
- [ ] Noted API secret (Client Secret)

### Phase 2: Google Apps Script Setup
- [ ] Created new Apps Script project
- [ ] Copied `Code.gs` content into project
- [ ] Filled in `SHOPIFY_API_KEY`
- [ ] Filled in `SHOPIFY_API_SECRET`
- [ ] Filled in `SHOPIFY_STORE_URL`
- [ ] Filled in `DRIVE_FOLDER_ID`
- [ ] Saved the script

### Phase 3: Deploy as Web App
- [ ] Deployed as Web App (Execute as: Me, Who has access: Anyone)
- [ ] Copied exec URL
- [ ] Pasted exec URL into `SHOPIFY_REDIRECT_URI` in the script
- [ ] Saved the script again after updating redirect URI

### Phase 4: Dev Dashboard Redirect URL
- [ ] Added exec URL to Allowed Redirect URLs in Dev Dashboard
- [ ] Saved/released as active version
- [ ] Confirmed version is **Active**

### Phase 5: OAuth Install URL
- [ ] Ran `buildOAuthInstallUrl()` function
- [ ] Opened View → Executions and copied the generated URL
- [ ] Opened the OAuth URL in a browser

### Phase 6: OAuth Flow
- [ ] Saw Shopify install consent screen
- [ ] Clicked Install
- [ ] Saw "✅ App Installed Successfully!" page
- [ ] Opened View → Executions in Apps Script
- [ ] Found and copied the `shpat_...` token

### Phase 7: Save Token and Redeploy
- [ ] Pasted token into `SHOPIFY_ACCESS_TOKEN` in `Code.gs`
- [ ] Saved the script
- [ ] Created a new deployment version
- [ ] Confirmed deployment is active

### Phase 8: Test Integration
- [ ] Ran `runOutOfStockReport()` manually (or via `?run=report`)
- [ ] Confirmed no 401 errors in execution logs
- [ ] Found HTML report file in Google Drive
- [ ] Verified log entry in "OOS Report Log" spreadsheet

## 7. Security Reminders

- [ ] `config.json` and `.env` files are in `.gitignore`
- [ ] Access token (`shpat_...`) is **NOT** committed to the repository
- [ ] API secret is **NOT** committed to the repository
- [ ] If credentials were accidentally committed: rotate them immediately in Dev Dashboard
- [ ] Periodically review which scopes the token has and reduce if possible
- [ ] If the integration is no longer needed, uninstall the app to revoke the token
